🔈 صدا شنیده نمی‌شود؟ نصب صدای فارسی ویندوز: تنظیمات ← زمان و زبان ← زبان و منطقه ← افزودن زبان ← فارسی ← «گفتار» را فعال کنید، سپس مرورگر را ببندید و دوباره باز کنید.
اندروید: تنظیمات ← سیستم ← زبان‌ها ← خروجی تبدیل متن به گفتار ← موتور Google ← نصب داده‌های صدا ← فارسی.
آیفون و مک: تنظیمات ← دسترس‌پذیری ← محتوای گفتاری ← صداها ← فارسی را دانلود کنید.
بعد از نصب، دکمهٔ «آزمایش صدا» را بزنید.
